# Phase 4: 一面题型编排与场景题优先 — Context

**Gathered:** 2026-09-07
**Status:** Implemented

## Phase Boundary

本阶段只改模拟面试的一面题型编排、阶段提示和动态题库素材过滤，不改独立问答、多会话、SSE 协议、raw → schema → compile 知识库链路或模型供应商。

## Decisions

- 一面不再自我介绍后立即连续深挖项目；先完成概念热身和两段场景推演，再进入项目。
- 场景题必须是简历之外的新背景，并带量级、目标和约束；追问覆盖容量、故障、监控、降级、权衡和验收。
- 项目阶段限制在第 7—11 次面试官发言，并按识别到的简历项目轮换；阶段结束后不得回到第一个项目循环。
- 普通 turn 与 SSE turn 复用同一动态提示构造器，避免两条链路题型漂移。
- 动态素材按当前题型过滤：概念只消费 questions，场景只消费 scenarios，手撕只消费 coding；没有合适素材时宁缺毋滥。
- qnum 表示本次即将生成的面试官发言，开场白为第 1 回合；结束边界必须对超过计划回合安全收束。

## Verification

- 阶段序列、项目轮换、题型素材过滤使用自动化测试验证。
- 保持 Python/JavaScript 语法、SSE 路径和 Electron 打包回归检查。
