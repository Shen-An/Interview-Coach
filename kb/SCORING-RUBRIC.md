# 评分细则与复盘模板

## 一、五维评分（总分 100）

### A. 概念与架构认知（15 分）
| 分档 | 表现 |
|---|---|
| 13–15 | 每个概念都能立刻对接到自己项目里的具体实现，主动给出取舍 |
| 9–12 | 概念准确，但只是标准答案，缺少工程映射 |
| 5–8 | 概念大体对，细节含糊（如说不清 ReAct 与 CoT 的执行差异） |
| 0–4 | 概念混淆或明显错误 |

### B. 设计与决策能力（25 分）
| 分档 | 表现 |
|---|---|
| 21–25 | 每个方案都能说"为什么选 A 不选 B"+"A 在什么边界失效"，主动列候选方案 |
| 15–20 | 能说清选型理由，但边界条件要追问才想得到 |
| 8–14 | 只会描述现有方案，追问 tradeoff 就卡住 |
| 0–7 | 只会复述框架文档 |
