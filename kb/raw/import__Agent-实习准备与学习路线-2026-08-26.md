**E136. Agent多工具调用时如何做好输出校验防止返回无效结果？** —— 网易Agent后端一面｜必考｜①Schema校验（JSON Schema约束字段类型/必填项/取值范围）②语义校验（LLM判断返回内容是否回答用户问题）③空值/异常检测④Fallback降级（校验失败切备用工具或直答）⑤日志记录入Badcase

**E137. CoT思维链对Agent执行效果有哪些提升与局限？** —— 阿里AI应用开发一面｜高频｜提升：推理透明化/复杂任务拆解/错误定位/Few-shot增强；局限：Token消耗3-5倍/幻觉传播/简单任务overhead/弱模型门槛/领域迁移困难

**E138. 并发场景下Agent会话怎么设计？** —— 腾讯后端一面｜高频｜①会话隔离（Redis key按user_id+session_id）②状态机FSM追踪阶段③乐观锁/版本号防冲突④限流熔断⑤异步+task_id轮询⑥空闲超时归档长期记忆

**E121. 用户问题连续触发多个工具时怎么避免工具调用混乱？** —— 美团Agent一面｜必考｜①DAG依赖图（无依赖并行）②调用ID追踪（唯一ID回传）③超时熔断（单工具3-5秒，总链路30秒）④schema校验⑤语义去重

**E122. RAG召回结果不理想从哪些维度排查？** —— 美团Agent一面｜高频｜五维：①索引侧（Embedding匹配度/IVF_PQ vs HNSW）②查询侧（Query改写/HyDE）③检索侧（Top-K/阈值/混合检索）④数据侧（Chunk大小/重叠率）⑤评测侧（Hit Rate/MRR/NDCG）

**E123. 向量数据库索引类型及适用场景？** —— 美团Agent一面｜高频｜Flat（<10万，100%召回）/ IVF_PQ（>100万，内存受限）/ HNSW（中等规模，高召回）/ DiskANN（超大规模，磁盘存储）

**E124. Agent Memory怎么设计，短期和长期记忆如何落地？** —— 字节AI应用开发一面｜必考｜四层：工作记忆（当前上下文）+ 短期记忆（Redis最近N轮+摘要，会话级）+ 长期记忆（向量DB+RAG检索，跨会话）+ 实体记忆（图DB用户画像）

**E125. 用户会话很长Prompt越来越大怎么处理？** —— 字节AI应用开发一面｜高频｜滑动窗口+摘要压缩+Token-aware截断+检索式回溯+分层上下文（系统区/工作记忆区/检索区/工具调用区分区）

**E126. Rerank重排序有哪些方案？** —— 字节AI应用开发一面｜高频｜Cross-Encoder（精度高慢）/ ColBERT轻量（低延迟）/ LLM-as-a-Judge（精度最高）/ 规则重排（时间/来源）/ LTR学习排序

**E127. 向量库和传统数据库怎么分工？** —— 京东大模型应用开发一面｜高频｜向量库存Embedding做语义检索（ANN）；传统DB存结构化数据做精确过滤。先向量库召回Top-K再用传统DB过滤

**E128. Agent工具调用失败怎么处理？** —— 蚂蚁智能应用开发一面｜必考｜超时→指数退避重试 / 参数错误→反馈模型自纠 / 服务端错误→熔断降级 / 权限错误→终止。结构化JSON返回+幂等key+超时上限

**E129. 大模型输出格式不稳定工程上怎么约束？** —— 蚂蚁智能应用开发一面｜高频｜JSON Schema强制 + Few-shot示例 + 正则兜底 + 重试改写Prompt + HITL（3次转人工）+ Jinja2模板填充

**E131. Badcase怎么定义？如何回流SFT？** —— 字节Agent二面｜高频｜三类：Review拒绝→纠错库→定期SFT / 用户不采纳→分析根因→针对性优化 / 高质量样本→正例库→Few-shot/DPO。链路：收集→标注→清洗→SFT pair→增量训练→A/B→发布

## 新场景设计题素材

**场景A：外卖平台智能客服系统设计（美团Keeta一面原题）**
- 业务背景：C端用户（餐品问题/找地址/赔偿/优惠券）+ D端骑手（派单异常/长时间无单）+ B端商户（入驻/结算/活动）
- 量级：日活千万级，非订单类走RAG，订单类走Skill工作流，投诉类走情感安抚+转人工
- 考察点：RAG vs Skill路由决策 / 三类用户差异化设计 / 订单类业务流程复杂为何用Skill而非知识库

**场景B：研究型Agent架构设计（字节二面原题）**
- 业务背景：高准确性场景（医疗/法律），幻觉率需<1%，引用错误率<3%
- 量级：多步推理任务，需Planner+Worker+Critic+Memory+Tool Registry五模块协作
- 考察点：可回退状态机checkpoint / trace回放完整决策链 / 人机协同审批点 / Badcase SFT回流

**场景C：AI办公入口三强格局分析（8月26日行业热点）**
- 业务背景：字节豆包工作（+飞书）vs 腾讯WorkBuddy（+微信AI）vs 阿里千问（+钉钉）
- 量级：桌面端AI原生办公智能体6月总访问量6000万（3月仅2000万）
- 考察点：多Agent协作产品设计 / 企业上下文感知 / "桌面Agent元年"概念
