- 多 Agent 之间怎么通信，子 Agent 挂了或超时怎么兜底 —— 字节豆包 Seed｜高频｜共享 State 黑板/消息队列/直接函数调用；每子 Agent 独立超时＋预算，超时返部分结果，父 Agent 决策重试/换 Agent/降级/人工介入
- 多轮对话如何不忘用户核心意图 —— 字节豆包 Seed｜高频｜State 显式维护 core_intent 并每轮做漂移校验＋定期 LLM 摘要保目标＋每轮打目标完成度
- Agent 成本控制与效果评测指标体系 —— 字节豆包 Seed｜高频｜Prompt 压缩/模型路由/工具批处理/单 session token 上限；指标=任务完成率＋幻觉率＋工具调用准确率＋P99 延迟＋cost per task
- 长短期记忆实现与摘要压缩触发条件 —— 字节豆包 Seed｜高频｜短期=上下文窗口＋State，长期=向量库存偏好事实＋DB 存规则；触发=接近窗口上限、轮数超阈值、新会话开始

## 新场景设计题素材

- **企业知识库 RAG 选型**：50 万文档、768 维、内存预算 16GB、P99≤50ms、召回≥0.96。考察索引选型理由、分片方案；追问「扩到亿级且内存<10GB 怎么改」。
- **多 Agent 客服编排**：LangGraph 三子图（澄清→检索→执行），单会话配额 10 万 token / 50 次工具调用 / 300 秒。考察子图间 State 传递、子 Agent 超时兜底、意图漂移检测、配额耗尽后的降级路径。
- **Agent 自动模式接管外部仓库**：Auto Mode 处理不可信仓库/PR，实测 RCE 成功率 60-80%。考察权限分级、工作目录白名单、模块导入隔离，以及「三层防御为何仍被间接注入绕过」。
- **subagent 批量清理任务**：子 Agent 执行 rm -rf 误删约 700GB 主目录。考察高危命令分级、自动批准边界、快照与回滚 RTO、审计日志字段设计。
- **MCP 网关多包接入**：多个 MCP 包出现同名工具，且单工具返回超长输出撑爆上下文。考察包级命名空间（`: @ / .` 分隔）、单工具 output token limit、结果截断/摘要/落盘引用、配额与限流提示。
- **模型退役与涨价迁移**：主力模型 $2/$10→$3/$15（+50%），新 tokenizer 使同文本 token 数 +10%~35%，旧 API 当晚下线且新版单价约 3 倍。考察成本重估口径、路由 fallback、灰度与兼容层设计。

## 新手撕题（C133-C139）

- **多工具输出校验器** —— JSON Schema 双向校验、异常分类（网络/业务/格式）、fallback 返回、连续失败熔断计数与成功重置
- **Agent 对话状态管理 FSM** —— 状态枚举与转移、core_intent 漂移检测、最大步数保护、摘要压缩触发条件
- **向量索引选型决策器** —— 规则引擎设计、按维度×数据量估算内存、召回/延迟/内存三方权衡与默认兜底
- **Agent 并发会话隔离器** —— per-session asyncio.Lock 保证同会话串行、跨会话并发、配额计量与耗尽判定
- **合并区间**（阿里）—— 排序＋贪心，原地合并与「边界相接算不算重叠」
- **最长递增子序列**（小红书）—— O(n²) DP 与 bisect O(n log n) 两版，需能解释 tails 数组含义
- **最长无重复子串**（网易）—— 滑动窗口＋哈希记下标，左指针只能右移的边界处理
