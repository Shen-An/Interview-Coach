## 新场景设计题素材

**S1｜上游定价与停服双重冲击下的模型路由治理**
业务背景：已上线的研发/客服 Agent，主力模型 9/1 起 $2/$10 → $3/$15，tokenizer 更新使同文本 token +10%~35%；同期另一路旧型号当晚全平台停服，替代型号单价约旧档 3 倍。
量级数字：复合涨幅 1.65~2.0 倍；可给的优化标杆是固定 prompt 5.7k→1k tokens（-82%）；日调用量/月账单由面试官按岗位自设。
考察点：成本归因（单价 vs token 增量）、缓存生命周期与稳定前缀设计、模型抽象层与能力矩阵、评测集回归、deadline 前的灰度与回滚、上游变更监控机制。

**S2｜企业内 MCP 网关中间件治理**
业务背景：内部接入多个 MCP server，部分慢启动会拖住首轮响应，部分返回含客户 PII 的原始数据，子 Agent 递归调用导致 token 失控。
量级数字：server 数量与 QPS 自设；可用锚点——固定工具 prompt 压缩目标 82%、慢启动 server 宽限期（秒级）、子 Agent 预算归口 root goal。
考察点：责任链式中间件设计、脱敏与截断策略、可选依赖的就绪状态机与降级、预算树与并发扣减、审计与可观测性。

**S3｜computer-use Agent 的桌面环境训练池**
业务背景：用数万台 Mac mini/Mac Studio 组成桌面环境池，为 GUI 操作 Agent 做强化学习采样，GPU 侧负责训练。
量级数字：环境实例数万级；单机并行 agent 实例数、样本回传带宽自设；硬件交付周期拉长（缺货）作为容量约束。
考察点：环境快照与快速重置、实例隔离与脏状态检测、失败环境自愈、采样-训练管道解耦与背压、缺货下的容量规划与弹性替代（虚拟机/云桌面）。

## 新手撕题
> 由 N26（Codex CLI v0.151.0）与 N23 衍生，文档未收录，适合作 Medium 级新题

- **MCP 工具结果中间件链（on_mcp_tool_result）** —— 考察点：责任链/装饰器模式、PII 正则脱敏、超长结果截断+摘要、异常规范化、中间件顺序与短路语义。
- **可选 MCP server 就绪管理器（grace period）** —— 考察点：`asyncio.wait_for` 超时、状态机 starting/ready/degraded、工具表热更新、首轮不阻塞的降级返回。
- **子 Agent 预算树记账器** —— 考察点：树形配额分配与回收、并发原子扣减、超额剪枝策略、按 per-agent 模型单价加权计费。
- **Tokenizer 变更成本回归对比器** —— 考察点：同语料双 tokenizer 计数、p50/p95 增幅分位统计、按 prompt 模板归因、扣除缓存命中后的真实账单估算。
